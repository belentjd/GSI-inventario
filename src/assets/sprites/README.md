Coloca aquí los PNG exportados por el editor, con el Id exacto de la persona como nombre: `001.png`, `002.png`, etc.

Después de añadir un PNG, haz commit y despliega de nuevo el sitio para que Astro lo incorpore al build. Las personas sin Id en el CSV no pueden tener sprite asociado.

`0.png` es el sprite genérico para personas sin imagen propia o sin Id en el CSV.
